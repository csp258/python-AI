## 快速启动

### 环境要求
- Python 3.10+
- Windows / macOS / Linux

### 一、安装依赖

```bash
pip install -r requirements.txt
```

### 二、选择启动模式

```bash
# Web 应用（推荐，可分享链接）
python main.py --web

# 桌面 GUI 应用
python main.py --gui

# 强制使用演示数据（跳过爬虫，快速体验）
python main.py --web --mock
```

首次启动会自动生成 500 条演示数据，无需配置 Playwright 浏览器。

## 功能特性

### 数据采集
- **Playwright** 真实浏览器自动化，突破 JS 反爬
- **XHR 响应拦截** 直接捕获后端 JSON 数据
- **智能降级**：真实数据不足时自动补充模拟数据
- 多关键词并行搜索：Python开发 / 数据分析 / AI / 机器学习等 10 类

### 数据处理（ETL Pipeline）
- 10 步管道：去重→缺失值处理→薪资清洗→学历标准化→经验标准化→城市标准化→公司标准化→技能提取→衍生特征→薪资分级
- 自动生成数据质量报告
- pandas 向量化操作，性能优异

### 可视化分析（23+ 图表）
| 类别 | 图表 |
|------|------|
| 分布与构成 | 城市岗位分布、学历饼图、公司规模环形图、薪资区间环形图、资历等级分布、岗位类型分布 |

## 技术亮点

1. **完整的 ETL Pipeline 模式** — 10 步管道处理，每步职责单一，使用 `.pipe()` 链式调用
2. **DAO 数据库模式** — 业务代码零 SQL，未来换 MySQL 只需改一个文件
3. **配置与代码分离** — `config.py` 集中管理所有参数
4. **多线程架构** — 数据加载在后台线程，UI 通过 `after()` 轮询更新
5. **数据质量意识** — 自动生成数据质量报告，标注缺失率和异常值
6. **Playwright 反爬突破** — `page.evaluate()` + XHR 拦截 + webdriver 标记抹除
7. **向量化优先** — pandas 向量化操作替代逐行循环，性能提升 10-100 倍
8. **有序分类变量** — pandas Categorical ordered=True，图表自动按逻辑顺序排列
