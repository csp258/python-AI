# 实验16：OpenStack安装与集群搭建 - 操作指南

## 环境说明

- **宿主机**: Windows 11 + VMware Workstation Pro
- **虚拟机**: Ubuntu 24.04 (VMware)
- **OpenStack**: MicroStack 2023.1 (Antelope)
- **实例镜像**: Ubuntu 22.04 Cloud Image

## 整体架构

```
Windows宿主机 (VMware)
  └── Ubuntu 24.04 虚拟机 (安装 OpenStack)
        ├── vm1 (OpenStack实例) ← 浮动IP
        ├── vm2 (OpenStack实例) ← 浮动IP
        └── vm3 (OpenStack实例) ← 浮动IP
```

---

## 第一步：在Ubuntu虚拟机上安装OpenStack

### 1.1 确保Ubuntu虚拟机满足要求

```bash
# 检查配置
free -h              # 内存 >= 8GB
df -h                # 磁盘 >= 50GB 可用
nproc                # CPU >= 4核

# 建议：在VMware中为Ubuntu VM分配至少8GB内存、4核CPU、80GB硬盘
```

### 1.2 执行安装脚本

将 `01_install_microstack.sh` 复制到Ubuntu虚拟机后执行：

```bash
chmod +x 01_install_microstack.sh
./01_install_microstack.sh
```

安装过程约10-15分钟。安装完成后会显示 Dashboard URL 和 admin 密码。

### 1.3 验证安装

```bash
# 获取admin密码
sudo snap get microstack config.credentials.keystone-password

# 查看OpenStack服务状态
source /var/snap/microstack/common/etc/microstack/admin-openrc.sh
openstack service list
openstack endpoint list
```

### 1.4 登录Dashboard

1. 在Windows宿主机浏览器打开: `https://<Ubuntu_VM_IP>/`
2. 用户名: `admin`
3. 密码: 上一步获取的密码
4. 域名: `Default`

## 第二步：在OpenStack中创建镜像和实例

### 2.1 通过Dashboard操作 (推荐)

#### 上传镜像:
1. 登录 Dashboard → 项目 → 计算 → 镜像 → 创建镜像
2. 镜像名称: `ubuntu-22.04`
3. 镜像源: 镜像文件
4. 格式: QCOW2
5. 下载地址: https://cloud-images.ubuntu.com/jammy/current/jammy-server-cloudimg-amd64.img

#### 创建实例:
1. 项目 → 计算 → 实例 → 创建实例
2. 实例名称: vm1 / vm2 / vm3
3. 选择镜像: ubuntu-22.04
4. 选择规格: m1.small
5. 网络: test (默认内部网络)
6. 安全组: default (确保SSH端口22开放)

#### 分配浮动IP:
1. 项目 → 网络 → 浮动IP → 分配IP给项目
2. 将浮动IP绑定到对应实例

### 2.2 通过命令行操作

将 `02_create_instances.sh` 复制到Ubuntu VM后执行：

```bash
chmod +x 02_create_instances.sh
./02_create_instances.sh
```

## 第三步：配置集群SSH免密登录

### 3.1 获取各实例信息

```bash
source /var/snap/microstack/common/etc/microstack/admin-openrc.sh
openstack server list
```

### 3.2 登录每台实例

```bash
# MicroStack默认CirrOS镜像的用户名
# CirrOS: cirros / gocubsgo
# Ubuntu: ubuntu

# 方式1: 通过浮动IP直接SSH
ssh ubuntu@<浮动IP>

# 方式2: 通过控制台登录
# Dashboard → 实例 → vm1 → 控制台
```

### 3.3 在每台实例上执行集群配置

将 `03_configure_cluster.sh` 复制到每台实例后执行：

```bash
chmod +x 03_configure_cluster.sh
./03_configure_cluster.sh
```

按提示选择主机名并输入其他节点的IP。

### 3.4 验证集群连通性

```bash
# 在vm1上
ssh vm2 hostname   # 应输出 vm2
ssh vm3 hostname   # 应输出 vm3
ping vm2           # 应能ping通
ping vm3           # 应能ping通
```

## 常见问题排查

| 问题 | 解决方案 |
|------|---------|
| snap安装慢 | 设置代理或更换snap镜像源 |
| microstack init失败 | `sudo microstack reset --force && sudo microstack init --auto --control` |
| Dashboard无法访问 | 检查防火墙: `sudo ufw allow 443 && sudo ufw allow 80` |
| 实例无法获取浮动IP | 检查external网络: `openstack network list --external` |
| SSH连接被拒绝 | 检查安全组是否开放22端口 |
