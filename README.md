# python-AI

Python 学习与 AI 项目合集，涵盖 Python 编程基础、数据分析与清洗、数据可视化、机器学习、网络爬虫及 AI 应用实践。

## 项目结构

| 目录 | 内容 |
|------|------|
| `python练习/` | Python 基础语法、面向对象、异常处理、综合练习 |
| `数据分析/` | Pandas、Matplotlib、电影数据分析 |
| `数据清洗/` | 数据预处理与清洗 |
| `AI运用/` | DeepSeek API 调用、Streamlit 入门、AI 助手 |
| `AI_Talent_Market_Analyzer/` | AI 人才市场分析项目 |
| `实验08-10/` | 网络爬虫：百度图片抓取、校园网搜索引擎、股票数据爬虫 |
| `实验11/` | 多因子量化选股案例 |
| `实验12/` | 学生成绩可视化展示 |
| `实验13/` | 电影推荐系统 |
| `实验14/` | 基于朴素贝叶斯算法的文本分类 |
| `OpenStack安装与集群搭建/` | OpenStack 环境搭建实验 |

## 技术栈

- **语言**：Python 3
- **数据分析**：Pandas、NumPy、Matplotlib
- **机器学习**：Scikit-learn（朴素贝叶斯）
- **爬虫**：Requests、BeautifulSoup
- **AI 应用**：DeepSeek API、Streamlit
- **环境**：Jupyter Notebook
